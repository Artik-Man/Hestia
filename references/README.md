# Справочные исходные репозитории

Каталог хранит локальные копии сторонних проектов, используемых только как технические примеры. Они не являются частью исходного кода или зависимостями Hestia и исключены из Git. Выводы исследования и ссылки на источники фиксируются в [документе об устройстве Keenetic](../docs/keenetic-platform.md).

| Репозиторий | Локальный каталог | Зафиксированная ревизия | Источник |
|---|---|---|---|
| `keenetic-sing-box-ui` | `references/keenetic-sing-box-ui/` | `e97ae1849b54ef627c644d5d4bac91d5899be4cf` (`main`) | <https://github.com/CoOre/keenetic-sing-box-ui> |
| `sing-box-lx` | `references/sing-box-lx/` | `2d9a0a52df7881f55484d48f9daecb21d135f3e9` (`lx`) | <https://github.com/Leadaxe/sing-box-lx> |

Копии клонированы рекурсивно с зафиксированными в репозиториях Git submodules. В `sing-box-lx` это также включает клиентские репозитории и их submodules; поэтому копия занимает заметно больше места, чем только исходники ядра. Обновление локальной копии намеренно не выполняется автоматически: сначала изучите изменения и обновите зафиксированную ревизию в этой таблице. Для проверки состояния выполните из корня Hestia:

```sh
git -C references/keenetic-sing-box-ui rev-parse HEAD
git -C references/sing-box-lx rev-parse HEAD
git -C references/sing-box-lx submodule status
```

Не переносите код из этих копий в Hestia без проверки лицензии, актуальной ревизии, зависимостей и применимости к требованиям проекта.
