# Модуль хранения

Используйте `internal/storage.Layout` для именованных ресурсов установленной системы. Потребители вызывают `storage.Installed()` — единственную точку выбора текущей платформы. `storage.Linux()` возвращает независимое значение со всеми прежними путями Linux; это не обнаружение платформы и не изменение глобального окружения. Не добавляйте новые абсолютные пути в предметные пакеты. Не меняйте путь без отдельного решения о миграции данных.

`OpenFile` принимает типизированные флаги доступа и защиты; сохраняйте прежние NoFollow, Nonblock, Directory и права создания. `Stat` возвращает владельца, группу, число ссылок и inode с признаком доступности. `MustStat` допустим только там, где контракт уже требует реальные метаданные ОС. `Flock` сохраняет блокирующий либо неблокирующий режим; закрытие дескриптора освобождает блокировку. Ошибки проверяйте через `IsWouldBlock` и `IsSymlink`.

Предметные Store и журнал binding сохраняют свои форматы, ограничения размера, атомарную замену, fsync и восстановление. Переносимые операции `os` не требуют обёртки. Новый платформенный адаптер обязан подтвердить семантику файловой системы тестами, прежде чем объявлять поддержку безопасного хранения.
