# Frontend панели

Каталог `frontend/` содержит Angular-приложение локальной панели Hestia, генератор API-клиента и браузерные проверки.

- `src/routes/` — страницы, открываемые Angular Router.
- `src/core/components/` — компоненты оболочки панели и повторно используемые компоненты страниц.
- `src/core/services/` — сервисы и состояние приложения; `api/generated/` содержит клиент и модели, сгенерированные по OpenAPI.
- `src/styles/` и `src/assets/` — общие стили и статические ресурсы.
- `scripts/` — генерация клиента из OpenAPI-контракта backend.
- `tests/` — проверки приложения, включая браузерные сценарии.

Команды сборки, форматирования и проверок перечислены в [`package.json`](package.json).
