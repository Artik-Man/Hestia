# Компоненты PrimeNG в панели Гестии

Версия пакета — 21.1.10. Экран использует директиву Button на нативной кнопке. Панель использует стандартную светлую тему Aura из пакета `@primeuix/themes`, включённого в сборку. Системный шрифт и локальные SVG позволяют открыть панель без внешнего интернета. Проектных обёрток над компонентами пока нет.

Таблица охватывает пользовательские компоненты и директивы из публичных точек входа этой версии. Имена в строках совпадают с разделами [документации компонентов версии 21](https://v21.primeng.org). Составные элементы, их свойства и ограничения описаны в декларациях установленного пакета `node_modules/primeng/types/primeng-<имя>.d.ts`. Иконки доступны из `primeng/icons`. Инфраструктура библиотеки, например типы, базовые классы и средства конфигурации, пользовательских элементов не добавляет.

Редактор требует Quill, график требует Chart.js. Эти компоненты и зависимости экрану просмотра не нужны. Для действия обновления используется семантика обычной кнопки, а состояние загрузки и ошибки доступно средствам чтения с экрана.

У каждой кнопки или ссылки с одной пиктограммой, включая свёрнутое меню, должна быть текстовая подсказка PrimeNG при наведении и фокусе с клавиатуры (`pTooltip`, `tooltipEvent="both"`). Задавайте доступное имя с тем же действием. Если действие меняется, обновляйте имя и подсказку вместе.

Палитра панели задаётся в `src/styles/theme.css`. Используйте общие переменные для поверхностей, текста, границ, действий и состояний. Компонентные стили задают компоновку, а preset PrimeNG использует общую палитру.

Для поиска компонентов используйте [указатель PrimeNG](https://primeng.dev/llms.txt), а для конкретного компонента — Markdown-страницу, например [Tooltip](https://primeng.dev/tooltip.md). Проектный MCP `primeng` позволяет запросить API и примеры. Его справочник версии 22.1.4 новее установленной библиотеки 21.1.10, поэтому перед применением проверяйте свойства по типам в `frontend/node_modules/primeng/types`.
