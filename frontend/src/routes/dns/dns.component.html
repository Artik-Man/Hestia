Автоматически добавлять частые домены

Служба автоматически прогревает имена по числу реальных запросов клиентов. Фоновые запросы сами не повышают частоту; исключённые имена не отбираются автоматически.

Минимум клиентских запросов к имени за последние X часов, чтобы оно оставалось в автоматическом прогреве.

Скользящий период, за который служба считает запросы клиентов для сравнения с порогом N. Если запросов станет меньше, имя выбудет из автоматического прогрева.

Как часто планировать фоновое обновление. Срок TTL тоже учитывается: обновление может понадобиться раньше этого интервала.
