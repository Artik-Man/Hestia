# Backend и API

Каталог `backend/` содержит Go-приложения Гестии, REST API и общие пакеты.

- `cmd/` — точки входа исполняемых команд, включая контроллер и сервер панели.
- `internal/` — внутренняя логика приложения: маршрутизация, DNS, панель, подключения, сеть и платформенная композиция.
- `pkg/` — переиспользуемые Go-пакеты, в том числе клиент Keenetic RCI.
- `tools/` — генератор OpenAPI-контракта и проверка документации Go-кода.
- `api/` — OpenAPI-контракт, используемый при генерации клиента Angular.

Сборка, форматирование и проверки backend запускаются командами из корня репозитория; их перечень приведён в [`scripts/readme.md`](../scripts/readme.md).
