# Независимая локальная проверка

Статус: поведение run 2 подтверждается сохранёнными исходниками и сырыми логами; локальная побайтовая пересборка ARM64 helper не подтверждена.

- Хеши исходника, конфигурации и runner в `evidence/run-2/` совпадают с `evidence/local-build.txt`; удалённые хеши helper и sing-box совпадают с теми же манифестами. На устройстве `sing-box version` и `check` завершились с кодом 0.
- В журнале ответа CNAME-пробы есть CNAME и конечный A в одном ответе, а счётчик `alias=0`; это доказывает передачу полного ответа, но не отдельный рекурсивный CNAME chase. Для первого запуска сохранён отдельный исходник CNAME-only и результат с одной CNAME записью.
- Во второй независимой пробе логи показывают UDP с `TC=true`, sing-box сообщает TCP retry, ответчик получает TCP для того же имени и возвращает A `192.0.2.62`; probe проверяет точное значение и `answers=1`.
- До/после совпадают четыре хеша routes/rules. Статус показывает ограниченный watchdog, успешный probe и завершение owned processes; cleanup подтверждает удаление обоих временных каталогов и освобождение портов.
- Попытка независимой сборки из снимка не закончена: каталог evidence не содержит `go.mod`/`go.sum`, а изолированная сборка с доступным кэшем без sum entry завершилась ошибкой. Не утверждаю, что локально воспроизвёл хеш helper.
