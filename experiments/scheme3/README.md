# Схема 3 в Lima

[Инструкция](../../deploy/docs/scheme3-deploy.md) описывает запуск двух ВМ и проверку HTTPS через Keenetic. Результаты сквозного опыта, включая обход для `example.com`, указаны в [протоколе сети](../../docs/validation.md#схема-3--wireguard-через-lima-вм-на-macbook).

4 ноября 2026 проверили, можно ли установить шлюз с панелью на чистую Debian 12 ARM64 и обновить его без смены ключей. Использовали рабочее дерево на MacBook, скрипты из `deploy/scheme3` и отдельную ВМ `hestia-s3-verify-1627`. Для воспроизведения прикладной проверки запустите команды `host.sh install`, `host.sh update` и `host.sh export-peer` из инструкции. Ожидаемый результат — активные службы, действующий API, маршруты в обе стороны и идентичный профиль. Все эти условия выполнены. [Свидетельство проверки](evidence/install-20261104.txt).

В этом прогоне использовали фиктивный интерфейс `lima0` внутри гостя и отдельный маршрут для проверки выбора шлюза. Подключение нового пира к реальному Keenetic и запуск macOS-установки моста требуют отдельного сетевого испытания.
