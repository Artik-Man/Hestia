# Независимая проверка свидетельств awg-tools

Проверяющий: независимая роль Evidence/Tester. Проверены сохранённые записи, локальные артефакты и доступный исходник. На роутер и ВМ не подключался.

## Подтверждено

- Хеш pinned динамического бинарника на хосте `7b5d8177fba2ebe1454390c069f7385401f95449c6f680e03090d368d7f16a56` совпадает с отчётом. Сохранённый транскрипт loader-пробы показывает успешную проверку переданного SHA, затем exit 1 для обеих команд (`--version`, `--help`) с отсутствующими `GLIBC_2.33` и `GLIBC_2.34`; probe-каталог удалён с SSH exit 0. Вывод ограничен этим dynamic ELF и Entware glibc 2.27.
- Локальная исходная копия имеет tag `v3.1.20260812`, commit `ee0f0a9aa34ff0a0da4b3433b9512781cfe02843`, совпадает с отчетом. В `src/wg.c` обработчики `--version` и `--help` возвращают ответ до dispatch subcommand.
- Архив Zig 0.17.1 в локальном временном каталоге имеет SHA-256 `75f1bc7a1e9852f17ec9a0c1895f767c4ec56d46bc8a834920eece1d0359dd8d`, совпадающий с build evidence. Указанный там static target `aarch64-linux-musl` и `LDFLAGS=-static` согласуются с типом фактического ELF.
- Финальный локальный артефакт `dist/keenetic-awg-runtime/awg-musl-static-aarch64` независимо имеет SHA-256 `a04ad65d551c6524f89d5939a39f382be7d1e5b48c0d833b1809480fc07adaf3` и определяется как статический ELF ARM64. В локальном temp source tree версия и commit совпали с закреплёнными значениями. Артефакт хранится вне Git, как указано в отчёте.
- Static router transcript подтверждает удалённое совпадение SHA до запуска, `--version` exit 0 с `amneziawg-tools v3.1.20260812`, `--help` exit 0 со справкой, удаление только собственного файла/каталога и SSH exit 0.
- Обе неуспешные передачи отражены: первая неверно указывала digest для dynamic binary и остановилась до исполнения; первая static передача имела имя tar member `wg` при проверке имени `awg` и остановилась до исполнения. Записи говорят об удалении только собственных временных файлов/каталогов. Исправленные пробы отделены от ошибок передачи.

## Границы проверки

На устройстве поведение независимо не повторялось; проверены сохранённые тексты и локальные артефакты. В отчёте правильно ограничен вывод запуском `--version`/`--help`: AWG daemon, UAPI, TUN, интерфейсы, VPN и трафик не проверялись. Транскрипты являются текстовыми протоколами, а не полным сырьевым SSH JSON transcript; локальный хеш артефакта, commit/tag и отдельные device hash/code/output/cleanup записи согласованы между собой.

## Итог

Материалы поддерживают вывод, что pinned dynamic binary не загружается через существующий Entware glibc 2.27 из-за требуемых более новых symbol versions, а конкретная статическая ARM64 сборка из pinned upstream исходника выполняет только `--version` и `--help` на KN-1012. Успех этих команд не подтверждает поддержку протокола AWG или VPN.
