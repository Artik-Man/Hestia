## Validation limits and observations

Standalone read-only managed-profile and sing-box validators were attempted
after installation but were stopped after device memory became constrained;
one readiness probe run concurrently with those validators segfaulted, then a
later single readiness probe succeeded. At the final resource sample,
`MemAvailable` was about 20 MiB and swap was absent. This is a meaningful runtime
limit: the package lifecycle is complete and two APIs respond, but the
physical-connections API and full profile/backend post-install checks remain
unverified under current router load. No OOM or segfault line was found in the
kernel log sample.

The first failed update exposed the 60-second init wait; raising it allowed
readiness. The next attempts identified a two-minute candidate backend timeout
and a five-second selector convergence timeout introduced by commit `880c07c`.
The final bundle includes bounded 10-minute backend validation, 15-minute
ingress migration, 47-minute supervisor boot readiness, and 30-second selector
convergence. This target run completed with all of those limits in place.

Local validation passed: `make build`, bundle manifest verification, build

Keenetic test binaries compiled; they were not executable on the macOS host.
