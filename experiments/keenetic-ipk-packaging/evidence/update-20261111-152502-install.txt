Результат установки
-------------------
`opkg install` прошёл target preflight и распаковал новую версию, но postinst
завершился ошибкой `Hestia supervisor did not become ready`. `opkg status hestia`
показывает версию `20261111-152502-77d6f73ccf3d`, статус
`install user unpacked`; package-maintenance marker остаётся, readiness и PID
markers отсутствуют. Повторные install/configure/rollback команды не запускались.

Postinst сначала вызывает `S99hestia configure-package`, который запускает
supervisor, и только после его успешного завершения вызывает
`-enable-keenetic-ingress`. Следовательно, данный прогон остановился на старте
supervisor до OpkgTun profile migration. Managed profile, controller snapshot и
sing-box config прошли отдельные read-only проверки после отказа. Наличие
`/opt/bin/hestia` подтверждено. Записей OOM в доступном kernel log нет; свежей
ошибки старта в `supervisor.log` или выделенных service logs не найдено.

IPv4/IPv6 route snapshots после отказа побайтно совпали с сохранёнными до
обновления. Использованная RAM оставалась около 208 MiB. Клиентский dataplane
не запускался.

Выводы о коммитах
-----------------
На момент первоначального preflight рабочая версия пакета уже была
`20261111-143406-07650c939f6c`, собранная до коммита
`77d6f73ccf3d` (`Add hestia-cli research file transfer`); она уже имела статус
`install user unpacked`. Сам `77d6f73` добавляет отдельную команду, документацию
и её сборку в bundles. Keenetic rootfs staging копирует явно выбранные бинарники
`hestia`, `hestia-panel` и `hestia-observe`; `/opt/bin/hestia-cli` в IPK не
включён. Старый и новый IPK содержат одинаковые 310 путей, ни один не содержит
`hestia-cli`. Это исключает прямое изменение Keenetic package payload данным
коммитом как причину отказа.

Причина, по которой supervisor не стал ready, остаётся неизвестной. До выяснения
ошибки startup/recovery не повторять `opkg install`, `opkg configure`, rollback
или reboot. Следующая диагностика должна получить stderr конкретного неудачного
старта supervisor и проверить startup recovery с сохранённым состоянием.
