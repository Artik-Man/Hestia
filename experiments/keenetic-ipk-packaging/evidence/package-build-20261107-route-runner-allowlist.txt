Вопрос: ограничен ли Keenetic route runner только командами, которые нужны Hestia AWG policy?

`keeneticroute.ExecRouteRunner` теперь отклоняет любые команды, кроме read-only `rule show`, чтения маршрутов в зарезервированных таблицах и чтения link inventory. Изменения разрешены только для точных IPv4/IPv6 unreachable guards, slot-bound IPv4 AWG default routes и mark rules, соответствующих зарезервированным table/mark/priority/device allocation. `show` переводится в BusyBox `list` только после проверки аргументов. `flush`, main table, чужие устройства, произвольные marks и таблицы отклоняются до исполнения.
