Bounded traversal review and Keenetic rebuild of the RCI schema helper
=====================================================================

Question
--------
Does the shared schema formatter reject oversized JSON branches before constructing and sorting their child-key lists, while retaining redaction and nested RCI error detection?

Change
------

`DescribeSchema` now detects nested `status: "error"` during its single bounded traversal. Before iterating an array or allocating/sorting object keys, it checks that the number of immediate children fits the remaining 256-node budget. Excessive branches fail with the existing redacted schema error. Values and arbitrary field names remain omitted by the allowlist formatter.
