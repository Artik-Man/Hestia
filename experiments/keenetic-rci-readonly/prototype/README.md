# Переиспользуемый Go-клиент RCI

Общие аутентификация, HTTP-транспорт и проверка ответа реализованы в `backend/pkg/keeneticrci`. Экспериментальные программы и продуктовые коннекторы используют один пакет: `FileTokenSource` читает токен, `Client.Do` выполняет объявленную операцию, а специализированные коннекторы преобразуют ответ в типизированные структуры.

Для текущего read-only опыта инвентаризации Ethernet используется команда из Go-модуля backend:

```sh
cd backend
go run ./cmd/keenetic-rci-ethernet \
  -base-url http://127.0.0.1:79 \
  -token-file "$HOME/.config/hestia/keenetic-rci-token"
```

Для KN-1012 сначала поднимите отдельный временный SSH-туннель с закреплённой проверкой host key к `127.0.0.1:79`, затем передайте локальный forwarded URL в `-base-url`. Команда намеренно не управляет SSH-туннелем: его создание, host-key verification и закрытие остаются частью плана конкретного эксперимента.

По умолчанию клиент разрешает только GET. POST должен быть объявлен как state-changing и отдельно разрешён через `AllowWrites`; этот переключатель сам по себе не является разрешением владельца на изменение устройства. Незащищённый HTTP принимается только для IP loopback; HTTP redirects и системные proxy отключены. Ответ ограничен по размеру и должен быть JSON. Ошибки не содержат токен или тело ответа.

Эта команда запрашивает только `GET /rci/show/interface` и печатает только типизированные поля Ethernet-портов. Не сохраняйте сырые ответы и не включайте в свидетельства адреса, MAC, DHCP, Wi-Fi, VPN или конфигурацию.
