# Прототип: ограниченные запросы CLI только для чтения

Каталог предназначался для небольшого помощника, допускающего только список запросов из соседнего отчёта. Он не должен принимать произвольные строки команд, пути RCI, HTTP-методы или тела запросов. Помощник не должен записывать файлы на роутер, запускать службу, открывать порт/слушатель или создавать сокет, кроме уже разрешённого SSH-транспорта. В сохраняемом отчёте нельзя раскрывать секреты, сырые сведения о интерфейсах и адресах, привязки DHCP, ассоциации, маршруты или полный дамп конфигурации.

Фактический прогон использовал только уже установленную команду <code>/bin/ndmc</code> через SSH. Файл помощника не создавался и не передавался на устройство. SHA-256 бинарника проверен до справки и успешных запросов. Условия и результаты приведены в [отчёте](../README.md).

Подтверждённые операции:

1. <code>ndmc -c 'show version'</code> — сохранить только модель, версию/сборку, архитектуру, имена компонентов и функций.
2. <code>ndmc -c 'show system'</code> — в памяти отфильтровать вывод и сохранить только агрегированные uptime/load/memory; удалить имена и прочие поля.
3. <code>ndmc -c 'show ip policy'</code> — передавать stdout напрямую потоком в фильтр размера и SHA-256; не выводить и не сохранять содержимое.

Не подтверждён доступ по HTTP RCI. Не использовать POST, чтение конфигурации, интерфейсов, DHCP, клиентов, журналов или токенов. Для каждого дальнейшего запуска нужны отдельная проверка отпечатка host key и SHA-256 исполняемого файла, запись времени/точной команды/кода завершения и сохранение сбойных попыток. Нельзя выполнять другие запросы без отдельного согласования.
