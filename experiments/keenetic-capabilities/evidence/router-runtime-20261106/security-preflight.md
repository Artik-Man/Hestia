# Проверка безопасности до проб runtime

6 ноября 2026 года проверен ограниченный план после разрешения владельца проверить VPN-компоненты и маршрутизацию без нарушения действующей сети. Аналитик ИБ не подключался к роутеру; заключение основано на локальных исходниках, архивах и свидетельствах чтения среды.

## Разрешённые границы

1. Однократная проба `netns-probe --probe-netns`: закрепление потока, один `unshare(CLONE_NEWNET)`, JSON и завершение всего процесса. Исходник `tests/lab/keenetic-capabilities/netns-probe.go` не содержит запуска программ, открытия сетевых сокетов, настройки интерфейсов, маршрутов, правил или записи файлов. При отказе ядра обходного пути нет. `go vet` для Linux ARM64 прошёл. Созданное при успехе пространство принадлежит только завершающемуся потоку; основная сеть не меняется.
2. Точные команды версии закреплённых бинарников: `amneziawg-go --version`, `awg --version`, `sing-box version`. Запуск с иными аргументами этим заключением не разрешён. Подтверждена ранняя ветвь возврата AWG по локальному закреплённому исходнику; для sing-box проверена [реализация команды версии v1.14.4](https://raw.githubusercontent.com/SagerNet/sing-box/v1.14.4/cmd/sing-box/cmd_version.go). Для amneziawg-go проверен [исходник закреплённой ревизии](https://raw.githubusercontent.com/amnezia-vpn/amneziawg-go/b5928efb6ca19f0153958460c3d141f04abc5c2e/main.go).
3. Перенос только проверенного архива в новый приватный временный каталог, сверка SHA-256 до распаковки и сверка вложенных файлов. Локально проверен архив `runtime-probe.tar`, SHA-256 `2837d9c7aa6ae610a2a5a9dac531df8ea1299388332191b43ae2bdaaba59f520`. Четыре записи — обычные `sing.tgz`, `amneziawg-go`, `awg`, `SHA256SUMS`; вложенный sing.tgz содержит ожидаемый каталог, лицензию и два обычных бинарных файла. Ссылок и выхода за каталог нет.

## Ограничения, влияющие на следующий этап

- sing-box и awg-tools требуют `/lib/ld-linux-aarch64.so.1`. Отсутствие загрузчика допускается зафиксировать отказом исполнения точного пути; установка, подмена загрузчика и библиотек запрещены в этом опыте.
- Один network namespace недостаточен для полной изоляции AWG: закреплённый исходник создаёт Unix-сокет в `/var/run/amneziawg`. Полный запуск требует также проверенной изоляции этой файловой области либо откладывается.
- `sing-box check` создаёт объекты через `box.New`; его нельзя считать чистой синтаксической проверкой и запускать как команду версии в основной среде.
- Отсутствие `unshare` и `/proc/self/ns/net` пока является наблюдением среды, а не доказательством причины отсутствия функции. Именно отдельный syscall-gate уточняет доступность. Отказ gate не разрешает пробовать маршрутизацию в основной сети.
- Таймаут локального SSH-клиента не гарантирует завершения удалённого процесса. Настоящие длительные runtime-пробы требуют отдельного удалённого ограничения времени и очистки строго собственных PID. Настоящее заключение охватывает только конечные команды версии и один syscall-gate; запуск туннелей, конфигураций и служб не разрешён.
- При версиях можно ограничить Go `GOMAXPROCS=1` и `GOMEMLIMIT=32MiB`; второй параметр является мягкой целью сборщика мусора, а не гарантией RSS. Эти короткие вызовы не являются нагрузочными испытаниями.

Блокирующих замечаний в этих узких границах не обнаружено. Готовность сетевой изоляции, VPN-туннелей, скорости и действующей сети по результатам этого ревью не заявляется.
