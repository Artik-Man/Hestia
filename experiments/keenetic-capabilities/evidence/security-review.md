# Проверка безопасности диагностического комплекта

Дата: 6 ноября 2026 года. Область: новая диагностическая команда, внутренняя логика инвентаризации и локальный сборщик. Полная Гестия и прежние runtime-компоненты этим заключением не сертифицируются.

Подтверждённых блокирующих замечаний не обнаружено. Инвентаризация читает фиксированный перечень источников с ограничением объёма; публикует только разрешённые поля и классифицированные ошибки. Команда не запускает обнаруженные программы, не меняет файлы/сеть, не создаёт соединения. Сетевые возможности остаются непроверенными. Отдельные тесты проверяют разрешённый `--inventory` и отказ при неверных аргументах без обращения к источникам.

Сборщик проверяет имя версии, передаёт аргументы без shell, компилирует из отдельного снимка, отключает скачивание toolchain/модулей и проверяет неизменность входов. Манифест охватывает новые исходники и файлы комплекта. Сборка предполагает доверенные локальные исходники и компилятор. SHA-256 подтверждает целостность, но не подлинность издателя.

Манифесты зависимостей не менялись; диагностический бинарник использует только стандартную библиотеку Go и код проекта. `go version -m` подтвердил Go 1.27.3, Linux ARM64, CGO отключён. Выполнены тесты диагностического пакета и 6 тестов сборщика — успешно.

Проверка `govulncheck v1.8.0 -mode=binary` завершилась кодом 0: известные уязвимости не найдены в проверенной базе на дату проверки. [Первоначальный вывод](security-govulncheck.txt) относится к промежуточному бинарнику с SHA-256 `dd6df1a5e8bafda902155a31b6d1a37465216905a7ac826e86fc59ff54fa7b27`.

После сборки повторно проверен финальный файл `dist/keenetic-diagnostics/20261106-keenetic-inventory-1/bin/hestia-keenetic-diagnostics`: SHA-256 `d8a58dac3bc9c327af9610f753525e591667fb70acd43e5ebb1a70e5758525ee`. Сканирование завершилось кодом 0, известные уязвимости не найдены. [Вывод финальной проверки](security-govulncheck-final.txt). `go version -m` повторно подтвердил Go 1.27.3, Linux ARM64 и отключённый CGO. Изменение версии сборки не изменило состав зависимостей.

Источники: [официальная история выпусков Go](https://go.dev/doc/devel/release#go1.27.3), [официальная база уязвимостей Go](https://go.dev/doc/security/vuln/database). Первоначальный запуск в sandbox не смог разрешить имя базы; повтор с разрешённым сетевым доступом завершился успешно. Доступа к роутеру и ВМ не было.

Аппаратное исполнение, совместимость ядра, производительность и сетевые изменения не проверялись. Отсутствие находок не является гарантией отсутствия неизвестных уязвимостей.
