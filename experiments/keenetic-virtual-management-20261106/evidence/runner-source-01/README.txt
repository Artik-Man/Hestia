Local orchestrator source snapshot captured before first mutating execution. It verifies the local SSH host-key pin and exact remote script SHA-256, uploads the source into a unique mode-0700 staging directory, verifies the remote hash, runs exactly one allowlisted profile with initial down/no arguments, retains only allowlisted remote status lines, then removes its own staging file/directory. It bounds each SSH phase and never persists raw interface output or stderr.
