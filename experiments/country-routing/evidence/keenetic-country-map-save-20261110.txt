# Сохранение карты стран на KN-1012 — 10 ноября 2026 года

## Цель

Устранить отказ сохранения карты стран при требовании оставить Zarubin и Laurel в группе «Остальной мир», не менять пользовательский профиль и маршруты Keenetic.

## Диагностика и проверка исправления

- Исходно в `/opt/share/hestia/geoip` отсутствовали GeoIP manifest и база; в `/opt/var/lib/hestia-geoip-overrides` отсутствовал точечный файл RU. Компилятор использовал Linux-пути вместо расположений Entware.
- После добавления GeoIP в пакет прямой `sing-box check` JSON-наборов на KN-1012 завершался из-за исчерпания памяти при разборе больших исходников.
- Исправленный пакет `20261110-215624-d9a573386528`, локальный IPK SHA-256 `8ffde6ea0580c40a161c31ba4baab979f68140e79261a8def9652e24145db907`, скомпилировал 249 бинарных `.srs` наборов.
- Сохранённый country-map request был включён: RU — группа по умолчанию, остальные страны — группа «Остальной мир». Профильный country-map compiler создал кандидат, а установленный sing-box успешно завершил `check` этого кандидата (`country-map-srs-candidate-ok`). Managed profile на роутере также прошёл проверку.
- Установка новой версии и единственная попытка `opkg configure hestia` завершились `managed service operation failed: smoke`; readiness не было. Логи supervisor содержали отказ установки Hestia TUN route; `sing-box` API на `127.0.0.1:9090` отвечал connection refused в момент selector preflight. Это состояние ограничило запуск сервиса и не связано с синтаксисом country-map кандидата.

## Восстановление и результат

- Перед восстановлением IPv4 default route hash был `f06c293b969676f64f57820103587f105084b9f90ca6c30640a925da0eba3871`; IPv6 default route отсутствовал (`e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855`).
- Штатный rollback использовал сохранённый ранее рабочий пакет `20261110-205949-d9a573386528` из root-only backup. Его `prerm` отказался удалять OpkgTun, используемый Keenetic policy; `opkg` сообщил об этом lifecycle отказе, но продолжил downgrade. Устанавливать новые версии после этого не стали.
- Финальный package status: `install user installed`, версия `20261110-205949-d9a573386528`. Supervisor readiness вернула 0; managed-profile и sing-box checks прошли. Процессы supervisor, panel и sing-box запущены.
- Финальные IPv4 и IPv6 default route hashes совпали с исходными. Секреты и полный профиль в свидетельство не включались.
- Пользовательская кнопка Save после отката не нажималась. Установленный rollback package не содержит новых GeoIP файлов и бинарных rule sets; успешная запись страны через UI не подтверждена.

## Границы и следующий шаг

Кандидат карты и бинарные rule sets валидны, но полный post-install smoke пакета с исправлением не прошёл. Сначала требуется отдельное устранение startup smoke / OpkgTun lifecycle взаимодействия по штатному плану, затем повторная установка `20261110-215624-d9a573386528`, readiness/API smoke, сохранение карты из UI и проверка, что Zarubin и Laurel остаются в «Остальном мире». Клиентский трафик и country routing не проверялись.
