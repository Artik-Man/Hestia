# Предыдущие версии probe

`probe-before-listener-unlink-fix.go`, `probe-before-diagnostic-logging.go` и `probe-before-postdelete-check-fix.go` — сохранённые либо реконструированные снимки исходника wrapper для анализа неудачных запусков. Файлы с `before-*` в имени, восстановленные удалением известных изменений из текущего исходника, являются **реконструированными пояснительными снимками**, а не точными побайтовыми копиями исторических сборок. Их исходные SHA и повторные сборки указаны в [reproduction.txt](reproduction.txt); полученные при поздней повторной сборке бинарные SHA не совпали с прежними удалёнными wrapper SHA, поэтому такое совпадение не заявляется.

`probe-before-clamp-aware-compare.go` и `probe-before-postdelete-check-fix.go` сохранены непосредственно перед правками и объясняют два ложных отказа проверки: сырые байты X25519 private scalar нормализуются upstream `clamp`, а после штатного завершения TUN интерфейс уже отсутствует и его sysfs flags читать нельзя. Сырых маршрутов и правил в этой папке нет.
