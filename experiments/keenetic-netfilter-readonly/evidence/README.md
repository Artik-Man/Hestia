# Свидетельства

До открытия gate и выполнения разрешённых read-only запросов свидетельств состояния KN-1012 нет. Не помещайте сюда сырые таблицы, адреса/домены домашней сети, клиентские данные, трафик или сведения из других исследований. Для каждого разрешённого запроса сохраняйте точную команду, UTC, хеш вызванного бинарного файла (если применимо), очищенный результат, код завершения и сбой, если он произошёл.
