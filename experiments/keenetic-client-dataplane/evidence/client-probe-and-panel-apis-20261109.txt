Read-only filesystem metadata showed `/opt/var/lib/hestia` exists as root-owned mode `0700`, but `/opt/var/lib/hestia/country-map`, `/opt/var/lib/hestia/dns-policy`, `/opt/var/run/hestia/dns/report.json`, and `/opt/etc/hestia/dns.json` were absent. The optional DNS worker therefore has no installed configuration/report. The country-map reader cannot create its first lock file while the country-map directory is absent.

Local diagnosis: `serviceSpec` for the panel did not pass the installed DNS policy path even though `runPanel` defaults it to empty and returns 503 in that case. Passing the fixed path allows the existing store to return documented first-install defaults when the policy file is absent; the independent warm report can remain unavailable until the optional DNS worker is configured. For country routing, the exact state directory must exist before the GET can initialize default assignments.

## Reproduction commands

Router trace:

```sh
printf '%s' '{"protocol":"TCP","source":"192.168.1.124","sourcePort":49336,"destination":"1.1.1.1","destinationPort":443,"durationSeconds":15}' | /opt/bin/hestia -traffic-trace
```

Client capture/probe, run after the router trace starts:

```sh
sudo -n timeout 15 tcpdump -nn -l -i lima0 '(src host 192.168.1.124 and src port 49336 and dst host 1.1.1.1 and dst port 443) or (src host 1.1.1.1 and src port 443 and dst host 192.168.1.124 and dst port 49336)' & capture_pid=$!; sleep 1; curl -4 --interface 192.168.1.124 --local-port 49336 --connect-timeout 3 --max-time 6 --resolve one.one.one.one:443:1.1.1.1 -sS -o /dev/null https://one.one.one.one/cdn-cgi/trace; curl_status=$?; wait "$capture_pid" || true; cat /tmp/hestia-client-trace-49336.log; echo curl_exit=$curl_status
```

Read-only API checks:

```sh
for path in api/country-map api/groups-and-rules api/dns/policy api/dns/warm api/dns/geoip; do
    curl -sS --max-time 8 -o /tmp/hestia-api-check.json -w "$path HTTP %{http_code} bytes=%{size_download}\n" "http://192.168.1.1:8080/$path"
done
```
