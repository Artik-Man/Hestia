- [Bash style guide](bash-style-guide.md) — стиль, форматирование и проверки Bash-сценариев.
- [Правила работы с виртуальными машинами](virtual-machines.md) — назначение ВМ, выбор `LIMA_HOME`, границы доступа и ограничения стенда.
