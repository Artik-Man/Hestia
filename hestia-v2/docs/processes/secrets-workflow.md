# Процесс работы с секретами

## Хранение

Храни секреты в каталоге `private/` в корне проекта. Каталог `private/` не должен попадать в Git.

## Ссылки из документации

Документы проекта могут ссылаться на секреты, размещённые в `private/`. Используй в документах ссылки на нужные файлы, не копируя содержимое секретов в документацию.
