# Entware

Entware — отдельная среда пакетов, размещённая на подключённом хранилище роутера. В проверенной конфигурации KN-1012 Entware установлен на USB-флешке объёмом 8 ГБ; его рабочее дерево доступно в `/opt`, а менеджер пакетов — `/opt/bin/opkg`.

Для проверенного устройства подтверждены архитектура процессора `aarch64` и архитектура пакетов Entware `aarch64-3.10`. Это разные идентификаторы: при сборке и установке пакета сверяй обе характеристики с целевым роутером. Наличие Entware и успешный запуск пакета сами по себе не подтверждают доступность функций ядра KeeneticOS или корректность сетевого dataplane.

Доступ к Entware на KN-1012 подтверждён по SSH через Dropbear на TCP-порту 222 с проверкой host key. Параметры доступа и подробности установки пакета описаны в [исследовании платформы](../../../../docs/keenetic-platform.md#подтверждённый-ssh-доступ-к-entware) и [процедуре поставки IPK](../../../../scripts/deploy/keenetic-ipk.md).

| Свойство | Проверенная конфигурация |
| --- | --- |
| Устройство | Keenetic Giga KN-1012 |
| Путь Entware | `/opt` |
| Менеджер пакетов | `/opt/bin/opkg` |
| Архитектура CPU | `aarch64` |
| Архитектура пакета | `aarch64-3.10` |
| Хранилище | USB-флешка 8 ГБ |

Эти сведения относятся к проверенной конфигурации. Перед установкой на другое устройство заново проверь модель, версию KeeneticOS, архитектуру Entware и свободное место.
