# BusyBox

Keenetic использует BusyBox для системных утилит. В составе Hestia для Keenetic BusyBox нужен в пакетных hooks, Entware init-скрипте, netfilter hook и как реализация команды `ip`. Список ниже составлен по текущей Keenetic-сборке Hestia и её установочным скриптам; это не полный перечень applets, встроенных в прошивку.

На KN-1012 проверен BusyBox 1.37.0. В частности, `/opt/sbin/ip` — ссылка на `/opt/bin/busybox`. Команда принимает `ip rule list` и `ip route list table all`; адаптер Hestia преобразует Linux-форму `show` в BusyBox-форму `list`. Наличие applet или команды чтения не доказывает поддержку всех вариантов записи и их семантики.

## Используемые applets

| Applet | Использование Hestia |
| --- | --- |
| `awk` | Читает поля `PPid` и времени запуска процесса из `/proc`, чтобы определить процесс `opkg` и проверить marker обслуживания пакета. |
| `cat` | Читает boot ID, PID supervisor и отпечатки файлов при проверках установки. |
| `chmod` | Устанавливает заданные права каталогов, маркеров и сгенерированных файлов. |
| `cut` | Извлекает SHA-256 из вывода `sha256sum` для проверки runtime-файла. |
| `id` | Проверяет, что IPK hook установки запущен от root. |
| `ip` | Через `/opt/sbin/ip` читает интерфейсы, маршруты и правила, а также управляет только зарезервированными Hestia маршрутами и правилами. |
| `ln` | Создаёт символическую ссылку с PID-владельцем для сериализации lifecycle-операций. |
| `mkdir` | Создаёт закрытые каталоги runtime, состояния и GeoIP overrides. |
| `mv` | Публикует подготовленные GeoIP-файлы и fingerprints атомарной заменой. |
| `readlink` | Читает цель символической ссылки lifecycle lock для проверки её PID-владельца. |
| `rm` | Удаляет только проверенные маркеры, PID-файлы, lock и временные файлы Hestia. |
| `sed` | Извлекает часть полей из `/proc/<pid>/stat` для проверки идентичности процесса `opkg`. |
| `sha256sum` | Вычисляет отпечаток бинарника `sing-box` при подготовке GeoIP rule sets. |
| `sleep` | Делает секундные паузы при ожидании остановки supervisor. |
| `start-stop-daemon` | Запускает и останавливает процесс supervisor; init проверяет наличие необходимых опций перед использованием. |
| `stat` | Проверяет владельца, режим, число ссылок и размер package-maintenance marker. |
| `uname` | Проверяет архитектуру `aarch64` в IPK preflight. |
| `usleep` | Делает короткие паузы при захвате lifecycle lock и ожидании readiness supervisor. |
| `wc` | Проверяет число строк и размер package-maintenance marker. |

## Используемый интерфейс `ip`

Hestia вызывает `/opt/sbin/ip` напрямую, без shell. Менеджер служб принимает этот путь, только если он разрешается в root-owned `/opt/bin/busybox`. Используются такие группы операций:

| Операция | Назначение |
| --- | --- |
| `-o link show` | Чтение списка интерфейсов. |
| `-4/-6 rule show` и `-4/-6 route show table <номер>` | Чтение правил и маршрутов; перед вызовом адаптер преобразует `show` в `list`. |
| `-4/-6 route add/del unreachable default table <номер> metric 32767` | Установка и удаление защитного маршрута только в зарезервированной таблице Hestia. |
| `-4 route add/del default dev awg<номер> table <номер> metric 100` | Установка и удаление маршрута выхода AWG в соответствующей зарезервированной таблице. |
| `-4/-6 rule add/del ...` | Изменение зарезервированных Hestia правил по метке и приоритету. Для защитного правила Keenetic-адаптер переводит действие `unreachable` в `lookup unspec type blackhole`. |

Адаптер проверяет аргументы до запуска команды. Перечень выше ограничивает поддерживаемые Hestia операции и не является обещанием совместимости всех возможностей BusyBox `ip`.

## Встроенные команды оболочки

Entware init и package hooks запускаются через `/bin/sh`. Они используют встроенные в shell команды и конструкции, которые не являются отдельными BusyBox applets, включая `[`, `:`, `cd`, `exit`, `export`, `kill`, `printf`, `pwd`, `read`, `return`, `set`, `true`, `umask` и `exec`. Скрипты также используют shell-конструкции `case`, циклы, перенаправления, подстановки и `trap`.

## Другие компоненты, не являющиеся BusyBox applets

| Команда или компонент | Роль |
| --- | --- |
| `opkg` | Entware package manager, который вызывает IPK lifecycle hooks; Hestia не подменяет его BusyBox applet. |
| `ndmc` | CLI KeeneticOS, который Hestia вызывает для управления интерфейсом OpkgTun и чтения состояния. |
| `/opt/bin/python3` | Запускает валидатор и подготовку конфигураций. |
| `sing-box` и динамический загрузчик `/opt/lib/ld-linux-aarch64.so.1` | Проверяют и запускают конфигурацию sing-box. |
| Hestia Go binaries | Выполняют управление службами, проверку процессов и файлов, RCI, IPC, сетевые операции и сетевые вызовы, для которых отдельные shell-команды не запускаются. |

## Проверка совместимости

Перед использованием новой команды или опции проверь её наличие и справку именно в BusyBox целевой версии. Изменяющие сетевые операции дополнительно проверяй на целевой прошивке с фиксацией исходного состояния и способом восстановления. Не выводи поддержку операции только из наличия applet или `/dev/net/tun`.

Перечень отражает используемые Hestia команды в установочном процессе, Entware init, netfilter hook, preflight и route adapter.
