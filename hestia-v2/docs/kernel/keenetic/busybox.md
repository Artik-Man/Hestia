# BusyBox

Keenetic использует BusyBox для ряда системных утилит в окружении роутера. Hestia должна учитывать фактические версии и доступный синтаксис команд: Linux-утилиты с теми же именами могут иметь другие параметры и вывод.

На KN-1012 проверен BusyBox 1.37.0. В частности, `/opt/sbin/ip` принимает `ip rule list` и `ip route list table all`; вариант `show`, применяемый некоторыми Linux-дистрибутивами, в сценариях для Keenetic следует переводить на проверенную форму `list`. Это подтверждено для чтения снимков IPv4/IPv6 routes и rules на данной прошивке. Наличие команд чтения не доказывает поддержку всех операций записи или семантики каждого атрибута.

Перед использованием команды в изменяющей операции проверь её справку и поведение на целевой версии, а затем отдельно подтверди побочный эффект и восстановление. Не делай вывод о совместимости только по наличию BusyBox applet или `/dev/net/tun`.
