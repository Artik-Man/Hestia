# OpkgTun

`OpkgTun` — тип интерфейса, который может быть создан Entware-программой через Linux TUN и представлен KeeneticOS как дополнительное подключение. В проверенном прототипе Linux-имя `opkgtun0` соответствовало интерфейсу Keenetic `OpkgTun0`.

На KN-1012 отдельный пакет `keen-mvp` создал TUN-интерфейс, который появился в инвентаре Keenetic и WebUI. Интерфейс был создан без добавления системного default route и без назначения клиентской policy; хеш основного IPv4 default route совпал до и после опыта. Этот результат подтверждает создание и видимость интерфейса в конкретной конфигурации, но не работу Hestia как шлюза.

OpkgTun сам по себе не задаёт безопасный путь пользовательского трафика. До полноценной приёмки нужно отдельно проверить владение интерфейсом, назначение policy, маршруты и правила, возвратный путь, блокировку при отказе и отсутствие обхода через WAN. Наблюдение OpkgTun в UI или успешное открытие TUN не подтверждает эти свойства.

Текущие результаты и границы описаны в [исследовании TUN-входа Hestia](../../../../experiments/keenetic-client-dataplane/README.md) и [опыте создания TUN на Keenetic](../../../../experiments/keenetic-tun/README.md). Исследование всей платформы находится в [документе Keenetic](../../../../docs/keenetic-platform.md).
