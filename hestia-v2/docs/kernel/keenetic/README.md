# Система роутера Keenetic

В этом разделе описана системная среда роутера, для которой проектируется и проверяется Hestia: KeeneticOS, Linux-ядро, Entware и доступные системные утилиты. Указанные версии и возможности относятся к проверенному KN-1012 и не переносятся автоматически на другие модели или прошивки.

Текущая подтверждённая база: Keenetic Giga KN-1012, KeeneticOS 5.2 Beta 3, ядро `4.9-ndm-5`, архитектура `aarch64`, Entware на USB-накопителе. Версии и возможности описываются только в пределах этой проверенной конфигурации и не переносятся автоматически на другие модели и прошивки.

## Бюджет оперативной памяти

Объём оперативной памяти роутера ограничен 512 МБ. Около 256 МБ занимает сам роутер. Для Hestia и всех её сопутствующих компонентов, доступно не более 200 МБ.

При обновлении не запускай новую версию параллельно с текущей. Сначала останови текущую версию Hestia и дождись освобождения занятой ею памяти; только после этого запускай новую версию.
