# Дизайн Keenetic как ориентир для Hestia

Замеры сделаны 5 ноября 2026 года в браузере по вычисленным стилям и границам элементов. Референс — «Системный монитор» Keenetic Giga, KeeneticOS 5.2 Beta 2, тёмная тема. Для сравнения открыта страница Hestia «Маршруты по странам». Ширина обеих страниц — 762 CSS-пикселя. Размеры ниже относятся к этому состоянию, включая свёрнутое меню Keenetic.

## Сравнение со страницей «Маршруты по странам»

В Hestia семь ссылок навигации занимают сверху область 690 × 96 px. Ниже идут надпись «Маршрутизация», заголовок 35/39 px и пояснение. Таблица начинается на y = 488, первая строка данных — на y = 564. Высота этой строки 71 px. Используется системная гарнитура, основной цвет текста — `#182F37`.

## Предложение для первого макета Hestia

1. Поставить имя Hestia в шапку высотой 64 px. Семь существующих направлений перенести в раскрываемое левое меню. В свёрнутом виде выделять «Маршруты по странам» фоном выбранной ячейки и голубой пиктограммой.
2. Начать рабочую область через 24 px после меню. Оставить один заголовок «Маршруты по странам». Рядом с переключателем разместить правило выбора группы, ниже — короткое указание, что черновик хранится в браузере.
3. Выровнять названия стран по левому краю, переключатели выбора — по центрам столбцов групп. Сохранить массовое назначение в заголовках. Для первого макета попробовать строку 44 px: на десяти однострочных записях это экономит 270 px относительно наблюдаемой строки Hestia. Высота 44 px — предложение для таблицы Hestia.
4. Сравнить макет с текущей страницей при одинаковой ширине. Проверить, сколько стран видно до прокрутки, различимы ли выбранная группа и массовое действие, помещаются ли длинные названия. Для широкого экрана и телефона отдельно проверить компоновку меню и таблицы.

Значения для шапки, меню и карточек измерены на системном мониторе. Перед утверждением оформления таблиц и форм стоит сверить их со страницей настроек Keenetic в той же теме.
