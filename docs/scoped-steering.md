# Автоматическое переключение UDP до одного адреса

Эксперимент соединяет измеритель Гестии с работающим sing-box на изолированном стенде ARM64. Для одной группы с двумя выходами выделен отдельный локальный набор правил. Основной выход выбирается обычной маршрутизацией группы. Адрес в наборе означает, что новые UDP-потоки этой группы до данного IPv4 идут через резерв. Администратор заранее связывает набор с этой группой, протоколом UDP и резервным выходом в конфигурации sing-box.

При подтверждённом преимуществе резерва контроллер добавляет только адрес назначения. При равенстве, недостатке проб или локальной ошибке сохраняет выбор. Для удаления исключения нужно измеренное преимущество основного выхода. Обновление публикуется атомарно. Запись в журнале сообщает, какой адрес и какую группу затронуло решение, какой выход выбран и на каких измерениях основан выбор. Публикация файла и доставка клиентского пакета проверяются отдельно.

Для приёмки нужны захваты реальных новых соединений до и после переключения. UDP до X должен перейти с FI-1 на FI-2, TCP до X и UDP до Y должны продолжить идти через FI-1. Домен группы RU с тем же реальным IP должен по-прежнему использовать RU. Затем проверяем сохранение FI-2 при равенстве и возврат на FI-1 при обратном преимуществе. Работающий sing-box сохраняет свой PID. Испытание полного отказа группы остаётся отдельной задачей.
