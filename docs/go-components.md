# Готовые компоненты для контроллера Гестии

Исследование от 4 ноября 2026 года для обсуждения первого MVP. Go остаётся предложением. Из перечисленного на нашем ARM64-стенде проверен sing-box 1.14.4 с двумя статическими выходами. Остальные кандидаты оценены по исходникам и документации. Добавление модулей в сборку и проверка конкретных версий предстоят после выбора стека.

## Как выбрать основу MVP

Первым кандидатом для опыта служит запущенный sing-box со статическими выходами и одним selector для финской группы. Стенд задаёт доступность вручную. Проверяем смену FI-1 на FI-2 без перезапуска процесса и без нового DNS-запроса клиента. При отказе всей группы отдельно проверяем отсутствие трафика на RU-1, включая внешний DNS. Действие блокировки нужно выбрать и проверить для используемой версии sing-box. [Сценарии приёмки](mvp-routing.md)

Если эксперимент проходит, первый контроллер на Go может использовать стандартный net/http для обращения к локальному API. В собственном коде останутся приоритеты доменных масок и групп, блокировка, выбор по стабильности и объяснение решения. По мере перехода ответственности за маршруты к контроллеру проверим netlink на Linux ARM64. Для оценки библиотек проб следующий отдельный опыт сравнит результаты с известными потерями, внесёнными через tc netem. Версии, лицензии, состояние сопровождения и зависимости зафиксируем для тех модулей, которые действительно войдут в сборку.
