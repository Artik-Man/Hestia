# Настройки пользователя

**Статус** — проект спецификации для согласования перед реализацией.

## Требования владельца

Панель должна поддерживать локальный вход администратора и смену его пароля в разделе «Настройки пользователя». Браузер и шлюз выполняют вход и смену пароля без обращений к сторонним серверам. Доступ к панели идёт по HTTP в доверенной локальной сети. Владелец принимает риск перехвата паролей и идентификаторов сессий на этом участке.

## Предлагаемый сценарий и критерии приёмки

1. При первоначальной установке администратор задаёт пароль в консоли шлюза. Шлюз сохраняет соль и хеш Argon2id. Обновление установки сохраняет действующий пароль.
2. После входа администратор открывает «Настройки пользователя», вводит текущий пароль, новый пароль и его подтверждение и нажимает «Сменить пароль».
3. При несовпадении подтверждения форма указывает на ошибку. При неверном текущем пароле сервер отклоняет запрос. В обоих случаях вход по прежнему паролю продолжает работать.
4. При успехе сервер сохраняет новый пароль и отзывает все сессии администратора. Панель открывает форму входа с сообщением «Пароль изменён. Войдите с новым паролем». В другом браузере следующий запрос к управляющему API также требует входа.
5. После перезапуска шлюза вход проходит только с новым паролем. Вход, смена пароля и повторный вход работают при отключённом WAN.
6. Сервер принимает запрос на смену пароля только из действующей сессии с защитой от межсайтовой подделки запроса. Пароли и идентификаторы сессий исключаются из журналов.
