# Настройки пользователя

**Статус** — прежний проект спецификации заменён требованиями к версии 1.0.0.

Актуальные требования к локальной аутентификации, настройкам учётной записи и первичной настройке Keenetic RCI собраны в документе [«Реорганизация Hestia», раздел «Объём версии 1.0.0»](../../Реорганизация%20Hestia.md#объём-версии-100). Старый сценарий с первоначальной установкой пароля из консоли и обязательным вводом текущего пароля при смене больше не является действующим предложением.
