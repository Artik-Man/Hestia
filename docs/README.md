# Документация Гестии

[Описание продукта для людей](../README.md) · [Полное оглавление](../DOCUMENTATION.md)

В этом файле собраны актуальные требования, архитектура, спецификации функций, планы проверок и эксплуатационные материалы. Инструкции агентам и правила работы находятся в [`agents/`](../agents/README.md), отчёты проведённых экспериментов и свидетельства — в [`experiments/`](../experiments/README.md).

При добавлении, перемещении, переименовании или удалении документа обновляйте ссылки в этом оглавлении. В документах функции отдельно отмечайте согласованное поведение, планируемые изменения и фактическое состояние реализации.
