# Применение привязки доменного списка

Администратор передаёт ID списка, его ожидаемую группу и новую группу. Пустая группа снимает привязку. Все маски и остальные списки сохраняются. Права пользователей на текущем этапе одинаковы для всех клиентов панели.

Синхронный запрос `PUT /api/list-binding` возвращает `200 OK` с ID списка и действующей группой после проверки применённой конфигурации. Неизвестный список или группа дают 404, конфликт ожидаемой привязки — 409. На панели без включённой записи операция недоступна. Сбой применения отражается ошибкой без раскрытия конфигурации туннелей. Приёмка проверяет маршрут нового соединения через другую группу, сохранность масок, отклонение устаревшей правки и восстановление при отказе. Для установки с профилем операция может перезапускать sing-box и контроллер, прерывая действующие соединения.

Панель передаёт три строковых поля привилегированному локальному помощнику. Помощник работает только с управляемой установкой. Экземпляр панели с произвольным снимком для просмотра управлять установкой не может. Проверки Host и происхождения запроса сохраняют границу доступа со стороны домашнего браузера.

## Запуск на управляемом шлюзе

Установите версию Гестии с поддержкой восстановления привязок и непустым профилем. Панели нужен доступ на чтение к снимку, поэтому добавьте её отдельную системную учётную запись в группу `hestia-snapshot`. Для примера с учётной записью `hestia-panel` откройте `visudo -f /etc/sudoers.d/hestia-panel-binding` и добавьте одну запись:

```sudoers
hestia-panel ALL=(root) NOPASSWD: /usr/local/bin/hestia -apply-binding
```

Запустите панель от этой учётной записи с параметрами `-enable-bindings -snapshot /etc/hestia/snapshot.json` и каталогом сборки `-assets`. Сервис передаёт запрос помощнику через стандартный ввод. Путь к профилю, имена служб и выполняемые команды заданы установкой. Без флага запись отключена, а обычный просмотр работает с выбранным снимком.

Пример для установленного профиля со списком `media`, который сейчас привязан к `fi`:

```sh
curl -i -X PUT http://127.0.0.1:8080/api/list-binding \
  -H 'Content-Type: application/json' \
  -d '{"listId":"media","expectedGroup":"fi","group":"ru"}'
```

При успехе ответ содержит `{"listId":"media","group":"ru"}`. Чтобы снять привязку, передайте пустую строку в поле `group`. Если другой администратор уже изменил группу, повторно загрузите текущий снимок после ответа 409. После обрыва HTTP-соединения проверьте текущую привязку перед новой попыткой.

Установка, экспорт и изменение привязок координируются через `/run/hestia-install.lock`. Если снимок доступности обновляет внешняя служба, она должна держать эту блокировку на время чтения и замены файла. Во время транзакции чтение установленного снимка может вернуть 503. Помощник сохраняет предыдущие файлы до проверки нового состояния. При прерванном применении восстановление предшествует запуску маршрутизации.

Во время работы за появлением журнала следит systemd. Если помощник завершился после запуска кандидата, служба восстановления получает блокировку, возвращает прежнюю конфигурацию и проверяет её. Повреждённый журнал сохраняется для диагностики, а маршрутизация останавливается, если прежнюю конфигурацию нельзя подтвердить. Время между аварией и восстановлением зависит от остановки и запуска служб.

Все три поля запроса обязательны, включая пустую строку для неназначенной группы. Неверная структура тела получает 422. Пока другую привязку применяют или установщик удерживает блокировку, запрос может получить 409. Запрос с другого сайта получает 403. Панель без режима записи либо шлюз, на котором применение подтвердить не удалось, возвращает 503. UI может вызвать типизированный метод `PanelService.applyListBinding()` из сгенерированного клиента.

`200` подтверждает завершение операции. При проверке нового поколения sing-box уже обслуживает трафик. Новое соединение может пройти по предложенной привязке до HTTP-ответа, в том числе если операция впоследствии вернёт 503. Откат восстанавливает маршрут для последующих соединений. Уже переданные пакеты отменить невозможно.
