# Проверки стенда и прежний disposable-fixture опыт

Основные команды разделены: [проверки исходников](../../../scripts/test-source/readme.md) и [проверки установленной версии](../../../scripts/test/readme.md). Общий смешанный runner заменён этими независимыми сценариями.

В этом каталоге остаются `install.sh` и `profile.json` для первоначального изолированного dev-стенда, а также узкие acceptance-helpers прежнего опыта. `acceptance.py` разрешает live CRUD/DNS только на `hestia-dev` с точным пустым deny-профилем и доверенным маркером; он не используется при обычном тестировании произвольного стенда. `host-ui.sh` и `ui_accept.mjs` проверяют тот же disposable fixture. `test_acceptance.py` и `ui_interrupt.mjs` проверяют отказ небезопасным предпосылкам и очистку при ошибке/прерывании без доступа к гостю.

Основной installed-test никогда не меняет реальную конфигурацию: CRUD/DNS выполняются с копиями установленной версии в изолированных лабораториях. Свидетельства прежнего запуска находятся в [отчёте](../../../experiments/dev-validation/README.md), правила доступа — в [описании ВМ](../../../agents/virtual-machines.md).
