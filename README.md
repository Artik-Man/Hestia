# Гестия (Hestia)

**Гестия (Hestia)** — название проекта и Linux-шлюза, который управляет несколькими интернет-подключениями. Гестия выбирает страну выхода по правилам для доменов, а подключение внутри страны — по качеству связи. Например, когда UDP-пакеты до одного сервера теряются на первом финском VPN, шлюз должен уметь перевести трафик к этому серверу на второй финский VPN. Если все финские выходы недоступны, трафик этой группы блокируется.

## Порядок работы

Согласованный порядок — **SDD → эксперимент, MVP или прототип при необходимости → TDD**. Сначала описываем ожидаемое поведение и критерии приёмки и согласуем их с Product Owner. Эксперимент отвечает на конкретный открытый вопрос; его результат и границы применимости записываем рядом со свидетельствами. Реализацию проверяемого поведения начинаем с теста, который воспроизводит требование и падает до внесения изменения.
